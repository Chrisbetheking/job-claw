# JobClaw 架构说明

## V0.1

```text
BOSS 直聘岗位页面
        ↓ Content Script
Chrome Side Panel
        ↓
@jobclaw/core
├── 偏好解析
├── 岗位匹配
├── 招呼语生成
└── 事实校验
        ↓
chrome.storage.local
├── 简历事实库
└── 岗位记录
```

当前版本不自动发送，不访问招聘平台私有接口，不上传 Cookie，也没有远程服务依赖。

## 后续版本

```text
Chrome 插件
    ↓ Native Messaging
JobClaw Desktop Bridge
    ↓
OpenClaw Skill / Cron / 消息渠道
```

桌面桥接后续负责本地数据库、任务队列、日报和 OpenClaw 命令白名单。Chrome 插件仍负责用户浏览器内的页面适配和最终人工确认。
