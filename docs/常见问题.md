# 常见问题

## 扩展加载失败

确认选择的是 `chrome-extension` 文件夹，里面应直接存在 `manifest.json`。

## 更新后还是旧版

停止任务，刷新扩展，关闭全部旧 BOSS 页面后重新打开。

## AI 连接正常但生成失败

检查模型名、余额和输出限制；重新生成一次，不要把“连接正常”和“生成成功”当成同一件事。

## PDF 乱码

优先使用 DOCX/TXT，或者安装 OpenClaw OCR。

## 文字没有发送

单条测试，确认右侧聊天区出现完整文字气泡。只有输入框里有草稿不算发送成功。

## 只发送图片

先关闭图片附件，验证文字稳定发送后再开启。

## OpenClaw 未连接

检查 Node.js、安装脚本和 `~/.jobclaw/bridge-error.log`。

## 提交 Issue 应提供什么

- JobClaw 版本
- Chrome 版本和 macOS/Windows 版本
- 脱敏截图
- 失败阶段
- 是否能稳定复现
- 导出诊断中确认没有 API Key 和私人简历信息
