# JobClaw 新手安装与使用

本文件是 README 中“零基础安装教程”的独立版本，适合转发给第一次使用 Chrome 扩展的用户。

![快速路线](images/00-quick-start.png)

## 安装扩展

![安装扩展](images/01-install-extension.png)

1. 下载 Release ZIP 并解压。
2. Chrome 地址栏输入 `chrome://extensions`。
3. 打开开发者模式。
4. 点击“加载已解压的扩展程序”。
5. 选择 `chrome-extension` 文件夹。

## 配置 AI

![配置 AI](images/02-configure-ai.png)
