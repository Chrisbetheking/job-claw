# Chrome 权限说明

JobClaw 只应申请实现当前功能所需要的权限。安装前请检查扩展目录中的 `manifest.json`。

## 主要权限

- `storage`：在本机浏览器保存简历文本、职业画像、设置和任务状态。
- `tabs` / `scripting`：识别并操作当前 BOSS 页面，恢复页面内容脚本。
- `sidePanel`：显示 JobClaw 侧边栏。
- `alarms` / `notifications`：定时维护任务状态并显示必要提醒。
- `offscreen` / `clipboardWrite`：把已确认的招呼语写入受控聊天编辑器。
- `debugger`：使用浏览器级可信输入完成聊天框聚焦、文字输入和发送确认。
- `unlimitedStorage`：保存较长简历、任务记录和本地分析结果。

`debugger` 是 Chrome 明确规定不能声明为可选权限的权限，因此当前可信输入版本必须在安装时声明。JobClaw 只在发送阶段短暂附加到目标 BOSS 标签页，完成后应立即断开。

## 网站访问范围

- `www.zhipin.com` / `app.zhipin.com`：岗位采集、详情读取和聊天投递。
- `api.deepseek.com` / `api.openai.com`：用户自行配置的 AI 分析接口。
- `127.0.0.1:17899` / `localhost:17899`：可选 OpenClaw 本地桥接。

项目不应申请全站 `<all_urls>` 权限，不应保存或导出 BOSS 登录 Cookie，也不应绕过验证码或安全验证。
