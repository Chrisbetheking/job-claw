# 架构说明

## 扩展

- `background.js`：任务调度、配置、AI Provider、状态持久化
- `content-v37.js`：招聘页面读取、筛选、会话操作和证据确认
- `sidepanel.js`：侧边栏交互
- `lib/`：去重、企业检查、任务状态、筛选、限速等领域模块

## 数据流

```text
侧边栏配置
→ 后台任务状态机
→ 页面内容脚本
→ 页面读取或用户授权的动作
→ 证据确认
→ 本地状态和日报
```

## 安全边界

- 高风险操作由用户主动启用
- 同一时间只执行一个发送动作
- 页面身份不确定时停止
- 只有看到真实发送结果才记录成功
- 登录验证和安全验证不会自动绕过

## OpenClaw

OpenClaw 通过 localhost HTTP 或 Chrome Native Messaging 与扩展连接。它只监听本机回环地址，并把数据保存在 `~/.jobclaw`。
