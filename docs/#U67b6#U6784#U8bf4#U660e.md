# Architecture overview

## Runtime

- `background.js`：任务编排、AI、存储、重试、可信输入与 OpenClaw 通信。
- `content-v37.js`：BOSS 页面识别、岗位采集、聊天页面操作与结果确认。
- `sidepanel.js`：五个固定页面及用户交互。
- `lib/conversation-identity.js`：HR/公司会话身份与投递锁。
- `lib/task-state.js`：任务阶段和进度元数据。
- `lib/job-priority.js`：岗位优先级和队列排序。

## Safety invariants

- 没有确认右侧文字气泡时，不发送附件、不计成功、不返回主页。
- 目标 HR 或会话明确冲突时，不发送。
- 外部网申岗位跳过。
- 同一任务重复重试会被锁定。
- 首次全自动成功一条后暂停验收。

## Test layers

- Unit：纯函数和模块。
- Integration：AI 画像兜底与页面接收器恢复。
- Regression：历史 UI9—UI37 关键问题。
- Validation：Manifest、CSP、HTML 结构、语法、敏感信息和发行构建同步。
