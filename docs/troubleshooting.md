# 常见问题

## 一直显示正在连接

1. 在 `chrome://extensions` 重新加载 JobClaw
2. 刷新所有招聘网站页面
3. 保留一个当前活动的职位页面
4. 再次启动模拟运行

## 城市或筛选没有生效

查看侧边栏中的“页面实际筛选”，确认配置值和页面值一致。城市应先切换，再提交关键词，之后应用其他筛选条件。

## OpenClaw 未连接

重新运行 `install-openclaw-macos.command`，然后检查：

```text
~/.jobclaw/bridge.log
~/.jobclaw/bridge-error.log
```

## 修改代码后页面仍是旧版本

重新构建扩展、点击“重新加载”，并刷新所有已打开的目标页面。

## 频繁出现异常或熔断

v2.2 默认会自动处理普通异常：

- 页面加载慢或脚本连接失败：自动重新连接或刷新页面
- 单个岗位输入框未加载：冷却当前岗位并继续后续队列
- 网络超时或平台频率提示：自动退避和降速，冷却后继续
- AI 或企业 Provider 暂不可用：自动切换本地模型、轻量算法或本地风险规则
- 搜索筛选未生效：重新进入目标城市和关键词页面，再按顺序设置筛选

以下情况不会自动绕过，需要用户处理：

- 验证码或安全验证
- 登录失效
- 当前 HR 与目标岗位不一致
- 已尝试发送但无法确认是否成功

处理完成后，在首页异常卡点击“已处理并继续”。系统会保留任务进度，不会从头重新扫描。

## 自动恢复一直重试

1. 查看首页或设置页显示的具体处理建议
2. 点击“立即自动修复”触发一次即时诊断
3. 确认当前只有一个活动的 BOSS 职位页或聊天页
4. 如果提示登录或安全验证，先在页面完成操作
5. 多次修复仍失败时，刷新 BOSS 页面后点击“已处理并继续”
