# Chrome 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存用户设置、简历和任务状态 |
| `tabs` | 查找用户当前打开的招聘页面 |
| `sidePanel` | 提供侧边栏界面 |
| `alarms` | 更新检查和本地任务调度 |
| `scripting` | 在已授权招聘页面恢复内容脚本 |
| `debugger` | 在需要精确输入时调用 Chrome DevTools Protocol |
| `offscreen` | 处理 PDF 等后台任务 |
| `clipboardWrite` | 用户主动复制内容 |
| `unlimitedStorage` | 保存较大的本地简历和任务数据 |

项目不会使用这些权限绕过登录、安全验证或平台访问控制。
