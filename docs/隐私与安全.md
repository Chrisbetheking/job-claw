# 隐私与安全

## 本地保存

扩展配置、任务记录、简历正文和职业画像主要保存在 Chrome 本地存储中。OpenClaw 数据默认保存在 `~/.jobclaw/`。

## AI 服务

当使用 AI 画像、岗位分析和招呼语生成功能时，相关文本会发送给用户配置的 AI 服务商。请自行阅读对应服务商的隐私政策。

## 不应提交到 GitHub 的内容

- API Key
- 真实简历和附件
- 手机号、邮箱、身份证和地址
- BOSS 私聊截图中的私人信息
- 本地日志、诊断和 `.jobclaw` 数据

## 桌面桥接

桌面桥接仅监听本机 `127.0.0.1:17899`，并限制为 JobClaw 扩展来源。它不会监听公网地址。

## 权限说明

- `storage`：保存配置和任务状态
- `tabs` / `scripting`：识别和恢复 BOSS 页面助手
- `sidePanel`：展示侧边栏界面
- `debugger`：执行可信输入、点击和发送验证
- `clipboardWrite`：把招呼语写入受控聊天编辑器
- `offscreen`：完成剪贴板写入
- `notifications`：任务状态提醒
- `unlimitedStorage`：保存简历、附件和历史任务

## 报告安全问题

请通过 GitHub Issue 提交脱敏信息，或微信联系 `easymoneysniperchris`。不要在公开 Issue 中粘贴 API Key 或真实简历。
