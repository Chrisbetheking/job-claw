# 开发路线

## V0.1（当前）

- Manifest V3 Chrome 插件；
- BOSS 直聘当前岗位读取；
- 右侧岗位分析面板；
- 本地简历事实库；
- 自然语言偏好解析；
- 基础匹配评分；
- 招呼语事实校验；
- 只填入、不自动发送；
- 本地记录与 JSON 导出；
- OpenClaw Skill 初始版本；
- 日报命令行原型。

## V0.2

- PDF/DOCX 简历导入；
- 结构化事实确认界面；
- 岗位列表去重与批量分析；
- 公司黑名单与岗位指纹；
- 多份简历画像；
- 可替换 AI Provider；
- 更稳健的平台选择器与页面快照测试。

## V0.3

- Native Messaging 桌面桥接；
- SQLite 数据库；
- OpenClaw 命令白名单；
- 定时生成日报；
- 微信、飞书或 Telegram 渠道通知；
- 待确认队列和远程暂停。

## V1.0

- 完整安装程序；
- 平台适配器开发规范；
- 自动化测试与版本升级；
- ClawHub 发布；
- Chrome Web Store 上架评估。
